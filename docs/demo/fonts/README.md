# Typeface

Overpass, by Delve Withrington and Red Hat. SIL Open Font License 1.1.
<https://github.com/RedHatOfficial/Overpass>

Overpass is an open interpretation of Highway Gothic, the lettering on road signs. GreenCharge
sends drivers to a charger, and those letters were drawn to be read at speed and through
blur, which is also what a shared screen on a video call does to text. The file is the
variable Latin build from Fontsource, bundled so the screen needs no internet connection.
