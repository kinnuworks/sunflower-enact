# Typefaces

Both are bundled so the screen looks the same with no internet connection.

- **Fraunces** (variable), by Undercase Type and contributors. SIL Open Font License 1.1.
  <https://github.com/undercasetype/Fraunces>
- **Atkinson Hyperlegible**, by the Braille Institute of America. SIL Open Font License 1.1.
  <https://www.brailleinstitute.org/freefont/> It was drawn to stay readable when letters are
  small or blurred, which is what a screen share does to them.

Files were taken from the Fontsource builds of each family (Latin subset).
