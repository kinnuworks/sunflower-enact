# ENACT Application Controller - Integration Guide

This file was generated by the ENACT SDK. It documents how the Application Controller was wired into this project and the manual steps that remain.

## Dependency

```xml
<dependency>
    <groupId>eu.enact-horizon</groupId>
    <artifactId>application-controller</artifactId>
    <version>1.0.0</version>
</dependency>
```

The Application Controller is published to Maven Central, so no local `libs/` jar or `system` scope is required.

## Selected modules

| Module | Primary service | REST base path |
| ------ | --------------- | -------------- |
| Load balancing | `LoadBalancerMetricsService` | `/api/v1/load-balancer/metrics` |
| Elasticity & auto-scaling | `ClusterScalingMetricsService` | `/api/v1/elasticity/auto-scaling/cluster-scaling-metrics` |
| Energy efficiency | `PowerMonitoringService` | `/totalPowerConsumption` |

- **Load balancing** (`loadBalancer`): Request, latency, connection, backend-health, protocol, TLS and edge-security metrics.
- **Elasticity & auto-scaling** (`elasticity`): Cluster pressure, HPA and container metrics, queue-aware and hardware-aware scaling signals.
- **Energy efficiency** (`energyEfficient`): Facility- and node-level power and energy monitoring, PUE and power-quality analysis.

## Configuration

The required keys were added to `src/main/resources/application.properties`. The application server runs on port 8080 and the management (actuator) server on port 8081.

## Kubernetes

See `kubernetes-snippet.yaml` in this folder for the container ports and health probes to merge into your Deployment and Service.

## Manual wiring (required)

The Application Controller is a Spring Boot subsystem. As its README notes, a host application should wire only the modules it needs. In your Spring configuration:

1. add component scanning for the Application Controller packages;
2. add entity and JPA repository scanning for the modules you use;
3. provide a datasource;
4. inject and call the primary service(s) listed above from your own wrapper services.

Start small: enable one or two modules first, verify they report, then expand.
